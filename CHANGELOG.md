# Changelog

All notable changes to BlackPoint are documented here.

## 0.1.0 - 2026-07-07

- Initial public release of BlackPoint.
- Added a macOS menu bar app for stowing distracting running apps without quitting them.
- Added global shortcuts for stowing the current app, stowing other apps, opening the panel, and filtered app switching.
- Added launch-at-login support, automatic re-stow behavior, and configurable shortcuts.
- Added English and Simplified Chinese localization with an in-app language selector.
- Added GitHub Pages website, install script, and release packaging workflow.
