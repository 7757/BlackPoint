# BlackPoint

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語** · [한국어](README.ko.md)

BlackPoint is a compact macOS menu bar utility that stows distracting apps without quitting them.

## Install

```sh
curl -fsSL https://7757.github.io/BlackPoint/install.sh | bash
```

You can also download the latest build from [GitHub Releases](https://github.com/7757/BlackPoint/releases/latest).

## Features

- Stow the current app with a global shortcut.
- Stow other running apps while keeping the current app visible.
- Keep stowed apps hidden when they are activated again.
- Optionally skip stowed apps in `Command + Tab`.
- Customize all shortcuts.
- Launch at login.

## Default Shortcuts

| Action | Shortcut |
| --- | --- |
| Stow current app | `Control + Option + Command + B` |
| Stow other apps | `Control + Option + Command + A` |
| Open BlackPoint | `Control + Option + Command + Space` |
| Switch to next visible app | `Command + Tab` |
| Switch to previous visible app | `Shift + Command + Tab` |
